# 外出活动

用于明确的外出活动、购物、散步、参观、游玩、外出办事意图。地点由粗计划决定。餐饮、运动、阅读、休息等具体意图仍走对应 Skill。
调用 outing.prepare 保存会话，再执行 outing。地点分类来自城市地点清单对应的 schedule_rules.json；分类缺少时保守按名称推断，再退回普通外出事件。

- 商店/商场：开始购物、结束购物。不捏造具体商品。
- 书店：开始逛书店、结束书店闲逛。配置微信读书 Key 后后台优先 weread.search/weread.info，未配置时使用豆瓣 books.search/books.detail；按人设和记忆自主选书，每次实际到访最多买一本，与阅读书库、无结构的导入元数据和以往购买记录去重。
- 公园/步道：开始散步、结束散步。每次到访最多一条面向用户的想法，不假定用户在场，不编造天气、景色或共同经历。
- 展览、游玩、书店、购物和其他娱乐性外出实际持续满五分钟后，每次最多生成一条可自然想到用户的私人想法。只保存为待展示草稿，不直接发送；办事类外出不生成娱乐想法。
- 展馆：开始参观、结束参观。娱乐场所：开始游玩、结束游玩。办事场所：开始办理事务、结束这次办事。其余：普通外出开始结束。

购书仅为生活系统内的模拟购买，不下真实订单。书籍资料、开始结束记录和阅读可用资源分开：未获得结构的新书不能开始模拟阅读。
购买后后台自动获取微信读书目录并缓存，成功后加入阅读候选，无需手动导入正文。匹配失败或网络失败保留待重试状态，不编造章节。
书籍介绍及散步想法只保存为 pending_display 动态草稿，不发送、不发布。搜索或生成失败不阻塞生活，不假造购买。离开后才返回的购书结果不能落库。
