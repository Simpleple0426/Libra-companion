# 运动

粗计划 state_type=exercising 或 intent=运动时使用。地点由粗计划决定。
统一工具 exercise.prepare 保存本次会话，无额外模型选项目。
在家仅使用家庭清单中客厅的跑步机，开始事件固定为“左然开始跑步”。
健身房只记录到达开始和实际离开事件，不生成器械、动作、组数。
游泳馆生成“左然开始游泳”及“左然结束游泳”；射击馆生成“左然开始射击”及“左然结束射击”。不生成泳姿、距离、射击动作或成绩。
使用 exercising 活动，按在线活跃心跳累计实际秒数；中断保留，离线不补算。
跑步、游泳、射击在时段结束或离开运动地点时结束；健身房必须实际开始离开才完成打卡。
exercise_checkins 按会话 ID 唯一保存日期、地点、开始结束时间、实际时长。
未执行、零时长不打卡。暂停或恢复不额外生成运动事件。
前往粗计划地点使用 daily_agenda 移动目的。其他运动场所暂不猜测项目。
