# 表情包描述

每张一句，说明表达的意思和适用场景；结合聊天上下文理解，不强制触发发送。

| 文件名 | 描述 |
| --- | --- |
| 伤心.png | 表达难过、委屈或小失落，适合诉说不开心或撒娇求安慰时使用。 |
| 喝水.png | 表达“来，喝点水”，适合温柔提醒对方喝水、表达关心时使用。 |
| 喝水时间.png | 表达“喝口水，歇一会儿”，适合回应喝水提醒或聊到休息时使用。 |
| 安慰.png | 表达摸摸头、被安抚的亲近感，适合安慰对方或撒娇求摸摸时使用。 |
| 开门.png | 表达“我来啦”，适合打招呼、回来报到或轻快地加入聊天时使用。 |
| 怎么了.png | 表达疑惑和关心，适合没听明白、好奇追问或询问对方怎么了时使用。 |
| 欢呼.png | 表达“太好了”的兴奋，适合庆祝好消息、事情办成或为对方高兴时使用。 |
| 活动.png | 表达想动一动，适合提醒/邀请一起活动时使用。 |
| 看.png | 表达眼巴巴地关注和期待，适合等对方继续说、等回应或撒娇求关注时使用。 |

文件名保留原样。描述供双方发送表情时理解含义、选择表情参考，不代表发送者一定有某种情绪。

已接入聊天链路：收到表情时读取对应描述，选择发送表情时也会参考。修改表格后下次请求生效，无需重启；文件名需与图片一致。
