# 工具执行

`application/tool_execution.py` 是聊天和后台任务的公共执行入口。`ToolDecision` 保留聊天意图解析、权限判断与业务收据；天气巡检、小红书发现、主动写信和回信保留自己的调度条件。

执行器按固定操作名选择服务适配器，保留底层参数校验、事务和持久化去重，不自动重试写入。所有调用输出 `[tool_execution]` 结构化日志，包含调用ID、UTC时间、来源、耗时和错误类型，不输出参数或结果正文。

`returned` 仅表示适配器正常返回，不表示业务成功或事务已提交。聊天仍以 `tool_results` 业务收据为准，写信仍以原有 `commit_artifact` 事务结果为准。聊天 trace 的 `tool_executions` 保存执行记录，后台调用可按日志中的来源排查。

App按钮对应的直接HTTP接口继续调用业务服务。后台检查不会为了执行工具而创建聊天回合。
