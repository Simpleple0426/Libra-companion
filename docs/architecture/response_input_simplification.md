# 回复输入简化（2026-09-17）

普通聊天沿用现有主线程，回复模型主要接收本轮用户消息、相关 LMC 记忆和可选的简短语气提示。附带当前时间与消息格式；实际使用工具时提供回执和必要的行动事实。最近对话保留在线程中，新线程初始化时补充历史。

- 身份：首次创建线程时注入，已有线程每日提醒一次。表情包目录和发送格式随这次提醒提供，不在普通消息中反复添加。每日提醒直接恢复原线程，不启动记忆检索、Response Plan 或对外消息投递。
- 记忆：只投影记忆内容、时间、归属、证据性质等必要字段，检索评分、查询计划和内部行为指导不传给回复模型。LMC 中真实的共同经历继续保留。
- 人物语料：用户消息先经现有情境判断模块判断当前是否明确难过或明显情绪波动。普通聊天、旧情绪、转述、否定和假设不应触发检索；无有效的当前原文依据或判断失败时不检索。此门控仍依赖辅助模型的语义判断，不能保证零误判。
- 剧情共同记忆：回复流程默认不召回。原存储和历史记录不删除。
- Response Plan：保留 `should_send`、内部 `reason`、`tone_guidance`；回复模型只接收前者与语气。语气为空时无特殊要求。情绪系统详细数据仍可供后台判断是否联系，不指定回复内容。
- 主动联系：以实际事件描述生成，不再执行调度器旧提示中的表达步骤；浏览所得笔记是否分享由回复模型决定，使用记录以真正投递的链接为准。
- 工具：未请求的空回执不注入；失败、待确认、已完成回执仍传递。发送权限、睡眠、冷却、写操作授权和主线程保护继续由程序执行。

验证使用隔离数据库和模拟模型。自然度和情绪门控质量仍需真实聊天观察，测试通过不代表已经验证语言效果。
