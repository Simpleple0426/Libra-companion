# 左然城市地点清单

状态：2026-09-27 已按用户要求将全部城市地点名称与分类同步到 `libra/world/schedule_rules.json`。外部地点的执行世界节点与通路尚未接入；家庭空间已另行导入。

## 来源与使用边界

初始地点名称及原分类提取自 [schedule_rules.json](../../libra/world/schedule_rules.json) 的 `locations`，日程生成入口为 [coarse_plan_generator.py](../../backend/life_prototype/coarse_plan_generator.py)；当前清单已合并用户后续增删与更名。仅整理地点资料，不沿用旧日程模板、活动概率、固定时间或通勤时长。

家和律所使用本轮讨论后的空间设定：

- [家庭空间与物品清单](左然家庭空间与物品清单.md)：双层住宅，厨房和餐厅分开，阳台位于一层客厅下方；Wi-Fi 为“律狮的专属频道”。
- [律所空间与物品清单](左然律所空间与物品清单.md)：重点细化左然办公室与茶水间，其他区域保持简洁；Wi-Fi 为 `ThemisLaw-Office`。

下列用途是依据旧分类整理的简要设计建议，不代表已经安排活动，也不代表原作官方设定。分类用于清单浏览，不是地图中的真实空间层级。地点的具体地址、相邻关系、距离、营业时间、人物与历史经历暂未确定。

## 6. 与新设定的合并方式

- 旧 `home_rooms` 不直接覆盖新家庭树，尤其两层卫生间需要区分。
- 旧 `home_exercise` 中的“跑步机”已按用户确认纳入“家 → 一层 → 客厅”，位于右侧靠窗、接近阳台处；它是物品，不作为独立城市地点计数。
- 其他地点第一版保留名称、用途、可用状态即可；需要精细互动时再补内部区域与物品。
- 本次没有新增助手此前举例的“公园”等地点；未名步道沿用原名。
- 名称中的区名保留，但没有据此推算完整城市地图、距离或通行时间。
- 这些地点存在于配置，不等于左然已经全部去过或认识其中的人。初始已知地点与相关经历需另行确定。
