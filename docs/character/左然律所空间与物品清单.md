## 对持续模拟有用的状态（设计建议）

| 对象 | 建议记录 | 暂不预设 |
|---|---|---|
| 文件与工作资料 | 所属事项、当前版本、位置、处理进度 | 真实案件、当事人和材料内容 |
| 档案 | 编号、位置、借出与归还状态 | 尚未设定的案件历史 |
| 会议室、会谈室 | 是否占用、预约时段 | 每天固定开会或有人来访 |
| 办公设备 | 是否可用、正在执行的任务 | 随机故障剧情 |
| 茶水间物品 | 库存、存放位置、使用状态 | 左然的饮食偏好与固定习惯 |

文件托盘里的“待处理”等标签表示物理归类，不替代任务的实际进度。把文件移动到“已处理”托盘，不能单独作为工作完成的依据。

文具、纸巾等无需第一版逐件模拟；需要支撑实际活动时再细化。案件进度与承诺应单独记录，不能只靠家具清单表达。
