# 左然的摘录本

阅读/观影累计活跃五分钟后，调度器在独立后台线程处理摘录，同一作品每天最多一批。每批由模型从候选中选择0至3条；没有结果、不确定归属或来源不可访问就跳过。失败不阻塞生活调度和进度心跳，次日再次阅读/观影可重新尝试。无需整本书正文、电影字幕或逐段理解。

来源只允许 `book.douban.com`、`zh.wikiquote.org`、`en.wikiquote.org`。书籍优先豆瓣原文摘录，再查中英文维基语录；电影只查中英文维基语录。豆瓣短评和影评不作为作品原文。维基语录排除无来源、误传、歌词、外部链接等区域；模型再检查候选是否属于作品。社区整理仍可能有误，不等同于原版逐字校勘。

检索与页面读取统一经过 `application/tool_contracts.py` 和 `ToolExecutor`，共享参数校验、截止时间和无敏感内容的调用日志。生活调度仍自行决定摘录时机。

`libra/quote_sources.json` 保存已核实的书籍来源定位。目前《无人生还》对应夏阳译、2019年新星出版社版的豆瓣页面；本地清单缺少ISBN，因此记录来源版本，但标记本地版次尚未核实。不修改本地共读书签。

每条包含作品、原句、语言、来源链接、来源位置（若有）、版本信息、摘录时间、当时活动及进度、左然的感想。英文自译独立保存并标明“译文（左然自译）”。感想可以自然地考虑用户、已有交流和想对用户说的话，不编造用户感受或共同经历。

按用户约定，不校验台词/摘录是否在当前进度之前，统一保存 `position_verified=false`，不虚构章节、页码或电影时间点。

原句经过Unicode规范化，忽略标点、空白和大小写，以数据库唯一约束永久去重，跨重读、重看、重启有效。另把同作品已有摘录交给模型，避免不同译法的语义重复；语义去重依赖模型判断，不保证识别所有异译。

持久化在 `data/life/local-life-v1/prototype.sqlite3`：

- `life_quotes`：摘录正文、出处与感想，作为唯一事实存储。
- `life_quote_jobs`：每天的任务，状态为 pending / working / done / skipped / failed。
- `life_memories`：左然自己的摘录感想及记录引用，方便以后召回。
- `quote-notebook/`：同数据库目录下的Markdown摘录文件，每条一份。

模型只能返回候选ID、译文和感想；程序负责原样复制原句、出处及去重。后台提交前已完成的模型结果可重放；数据库记录先提交，文件随后导出。可用 `quote_notebook.export(cog)` 从数据库补回丢失的文件。
