# 休息 Skill

rest.prepare 通过统一工具层准备会话；rest 活动只记录开始和结束，不需要额外内容生成调用。

触发规则：明确意图“休息”，或 resting 且没有具体活动意图。resting + 阅读 / 看电影 / 看电视分别走原有对应 Skill。free 无意图不自动视为休息，睡前准备及等待晚安继续由个人护理处理。

开始事件“左然开始休息”，结束事件“左然结束了休息”。按实际到达地点开始；日程结束、中断、切换或恢复时结束。同一会话只记录一对事件。恢复以当前时刻结束，不编造离线结束时间。全程保持清醒，不自动入睡。

数据库 life_state.current.rest_sessions 保存地点、计划时段、实际开始结束时间；events 和 life_memories 保存已发生的事件。生活状态 API 和聊天上下文提供会话状态。不展示活动进度，不额外模拟具体休息方式。
