# 粗计划管理地点

用户确认移除独立移动执行。正式 Life 模式不接受 moving / serving 的开始或恢复，不再生成房间路线或移动检查点。旧移动记录仅保留为历史审计，运行中的旧任务会关闭，不补算路线进度。

粗计划中的通勤时段保留，开始记录离开，结束记录到达。当前位置随后由当前粗地点和细活动选择的房间确定；细活动不能选择另一个粗地点。房间切换没有单独耗时，不生成离家动态。工作、家务、备餐到用餐沿用其自身进度，不因位置切换而自动完成。

陪伴中不运行地点切换。退出陪伴仍使用既有的粗计划恢复流程。

主页和详情页动态只展示已提交事件，不再把已到开始时间的计划拼成“正在洗澡”等事实。日程页继续显示粗计划。

首次升级不会将历史 22:35 到家改写为 22:21。新规则从生效后的当前粗计划开始管理位置。原型测试与历史结果解析保留旧结构兼容能力，正式执行入口拒绝旧移动动作。
