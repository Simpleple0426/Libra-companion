# 个人护理 Skill

对应粗计划中的洗漱、洗澡和准备睡觉。地点仍由粗计划决定；到达卫生间或卧室后，统一工具 `care.prepare` 保存确定性步骤，不额外调用模型拆解步骤。

| 意图 | 步骤 | 默认模拟活跃时长 |
| --- | --- | --- |
| 晨间洗漱 | 刷牙、洗脸、整理仪容 | 4 分钟 |
| 睡前洗漱 | 刷牙、洗脸 | 3 分钟 |
| 晚间洗澡 | 洗澡、擦干、吹干头发 | 沿用已有洗澡时长配置 |
| 卧室睡前准备 | 换睡衣、整理床铺、放下手头物品 | 3 分钟 |

这些时长用于生活模拟，不是实际设备监测。当前位置和步骤存入生活数据库当前状态的 `care_plans` 与活动记录。每次心跳推进步骤；暂停、超过 90 秒的未观测间隔和重启不补算。粗计划时段结束后停止旧活动，不伪造完成。睡前准备与随后等待晚安共享当日完成记录，避免重复换睡衣。

开始、暂停、恢复、完成记录事件及生活记忆。完成回执允许清洁度和舒适度更新；卧室睡前准备只允许舒适度更新。不会直接修改睡眠状态，仍由既有晚安链路触发入睡。旧版正在执行或已经完成的洗澡记录继续有效。

实现：`backend/life_prototype/skill_personal_care.py`；运行时技能说明：`backend/life_prototype/skills/personal_care/SKILL.md`。客户端无需新增表单或重新安装。
