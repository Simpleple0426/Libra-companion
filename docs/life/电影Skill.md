# 电影 Skill

## 自主选片、豆瓣和本地影评

观影过程中还会低频生成[摘录与感想](摘录本.md)，与完整看完后写影评分别处理。

影评会同时考虑用户：召回相关用户偏好与交流记忆，允许自然融入想对用户说的话、联想到用户的感触或共同观看的邀请。没有依据时不编造用户感受或共同经历；记忆摘要区分“想说/想邀请”和已经发生的交流。

优先选择已有清单，也允许通过豆瓣发现新电影。新片必须先获取详情并核实片长；多版本片长需要明确选择版本，不能猜测。新增候选保存在数据库的 `life_evidence/discovered_movie`，资源同步后仍保留。

使用 `jackjin1997/douban-mcp` 的只读 CLI（与 MCP 共用工具实现），依赖锁定在 `backend/integrations/douban/package-lock.json`。部署时在该目录执行 `npm ci --ignore-scripts --no-audit --no-fund`。详情的 `duration` 是可选字符串，可能包含多个版本。短评接口获取少量网友短评，不提供长影评或关键词搜索。

如豆瓣要求登录，将 Cookie 保存在本机 `config/secrets/douban-cookie.txt`；也支持 `DOUBAN_COOKIE` 环境变量。不要提交或发送 Cookie。没有可用登录态时，选片退回现有清单，影评使用已有电影知识卡；连本地资料也不足时保留任务等待资料，不编造剧情。

每轮完整看完后，在 `life_movie_reviews` 创建一个持久化任务；中断或只看一部分不会创建。调度器空闲时调用模型，结合左然设定、影片资料和历史记忆写影评，也可先参考最多五条短评。重看完整结束会产生新的一篇，同一轮重试不会重复写入。模型失败最多尝试三次后标为 `needs_review`，资料缺失则保留为 `waiting_sources`。

影评全文和任务状态保存在 `data/life/local-life-v1/prototype.sqlite3` 的 `life_movie_reviews`；Markdown 文件保存在同目录下的 `movie-reviews/`。简短个人观点写入 `life_memories`，供下次选片和重看时召回。影评只保存在本地，不发布到豆瓣。观看过程仍按实际活跃时间推进，不调用模型。

指令：`backend/life_prototype/skills/movie/SKILL.md`。影音区 free 时段加载，意图为“看电影”时优先。

## 清单与片长

候选来自 `libra/movie_knowledge/catalog.json`，沿用用户确认的左然电影清单及版本辨认结果。`watched` 表示既有设定中看过，允许再次观看，不把这一标记当成当前播放进度。

参考片长及来源保存在 `libra/movie_knowledge/runtimes.json`。原清单 29 项，其中“爱在三部曲”展开为三部独立电影，共 31 个可选目标。尚未辨认的名称和被排除的条目不会进入候选。

片长采用明确标注的参考版本，不代表本地视频文件的精确时长。多版本条目保留 edition，例如《海上钢琴师》采用原版 165 分钟，《乱世佳人》采用不含间歇音乐的影片时长 221 分钟；对应来源链接存于数据文件。不同版本不得混用进度。

## 运行流程

1. 细计划检索“粗计划意图 + 候选电影名”的生活记忆，把候选、已有进度、完成轮数、片长交给模型选片和决定本次时长。
2. 程序计算预计观看范围，计划本身不增加进度。开始或续看写入 `左然正在观看《电影》，进度：HH:MM:SS / HH:MM:SS（百分比）`。
3. 运行时根据正在观看的实际活跃秒数推进，定期保存。离开影音区、切换活动、时段结束时结算不足一个检查点的剩余时间，写入结束事件；达到片尾时标记本轮已看完。

进行中的一轮固定使用开始时的参考片长和版本。未完成继续同一活动；再次选择已完成影片会开始新活动、进度从零开始，历史活动与完成次数保留。不无理由连续重播刚看完的电影。

## 持久化与 token

生活数据库 `life_state/current` 内：`viewing` 保存当前轮的累计秒数；`viewing_progress` 保存片长、百分比、版本、活动 ID、完成次数；`activities` 保留每轮历史和当前恢复点。

开始与结束事件存入 `events`，由调度器直接收录进 `life_memories`。过程中不调用剧情理解、影评、台词或逐检查点的记忆加工模型。选片仍使用细计划模型与既有记忆检索。

暂停、服务离线不增加观看时长，重启恢复最后保存的位置。后台忙于模型调用或聊天而延迟结算时，持续观看的时间按实际经过秒数累计，不再因心跳间隔超过 90 秒就整段丢弃；结算最多到本段安排的结束时间和影片末尾。明确的重启／离线恢复仍跳过未观测间隔。此进度属于左然生活模拟，不是手机播放器遥测，也不修改用户电影收藏或共读书签。

当前状态接口在本进程持有生活工作器且左然清醒时，按同一计时规则返回截至查询时的观影位置，不因查询而写库。手机动态详情顶部显示片名与“已看时长／总时长”，每 10 秒刷新；下方历史动态保留开始或续看当时的进度。此前已经丢弃的历史时长不会自动重算。
