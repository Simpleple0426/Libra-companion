# 看电视 Skill

粗计划的“看电视”意图对应 television Skill，与“看电影”流程独立。

1. 到达粗计划地点，确认家庭清单中存在可用电视。
2. 统一工具 television.prepare 保存本次会话；准备阶段不产生开机事件。
3. 开始 television 活动，生成“左然打开了电视”。
4. 时段结束、被中断、切换活动或重启恢复结束会话时，生成“左然关掉了电视”。

不选择节目，不显示具体内容，不保存节目进度，没有额外内容生成调用。每次粗计划会话只开关一次；结束后不在同一时段反复重开。

life_state.current.television_sessions 仅保存会话、设备、地点、时段及模拟开关状态/时间；events 保存开关事件，life_memories 接收已发生事件。生活状态和聊天上下文提供会话状态。底层活动的通用 progress 占位字段保持为零，不作为观看进度展示。

恢复时在当前时刻结束会话，不伪造离线期间的关机时间。本功能描述生活模拟中的开关动作，不控制真实电视。
