# 阅读 Skill

运行时指令位于 `backend/life_prototype/skills/reading/SKILL.md`，由细计划在有合法阅读候选时加载。

1. **选书**：候选来自私有书库 `reading/books/*/manifest.json`，必须有对应的分块文件。只把书名、已有进度等元数据和相关记忆交给选书模型；知识卡不作为阅读候选。目前实际导入书为《无人生还》。
2. **安排**：选择书籍和阅读时长后，程序使用章节名称、分块顺序和字数计算预计起止章节。开始或续读时写入 `左然正在阅读《书名》（章节位置）` 事件。预计范围不计入已完成进度。
3. **结束**：运行中定期保存进度；离开书房、切换活动、时段结束或全书读完时结算，并写入 `左然结束阅读《书名》，进度：章节位置` 事件。事件直接进入生活记忆，不调用模型生成理解、摘要或读书笔记。

本功能不读取分块正文，不调用逐段阅读模型。进度是模拟阅读进度，不代表模型已经理解内容。默认每分钟 400 字符，可通过世界配置 `reading_simulation.characters_per_minute` 调整（大于 0，最多 3000）。

另有独立的低频[摘录本](摘录本.md)：在阅读过程中从限定网站选取少量短句并写感想，不改变结构阅读和计时规则。

进度保存于生活数据库 `life_state/current` 的 `reading` 和 `reading_progress`，活动保存章节计划与恢复点。使用书籍 ID 和结构版本隔离；历史正文阅读偏移保留，并作为估算初始位置迁移一次。不会修改用户的共读书签。

重启只恢复最后持久化的进度，不计算离线时间；单次心跳间隔超过 90 秒也不补算。阅读范围不超过分配时段与全书结尾。开始、结束事件和结束进度在同一事务提交。
