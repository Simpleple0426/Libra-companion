# 工作 Skill

work.prepare 通过统一工具层生成并幂等保存 work_sessions 和 work_steps（life_state.current）。每个粗计划一组步骤；步骤顺序按粗计划 ID 稳定选择，长时段安排讨论或委托人沟通、资料查阅、可选茶水间短休、工作笔记。短时段保持一到两项，避免频繁切换。准备阶段没有事件，不调用法律检索或文书生成模型。

每段活跃时长按心跳推进，超过90秒间隔或恢复服务不补算；活动打断保留进度。同段恢复原步骤，跨粗计划仅保留工作类型供衔接，不将未执行步骤写成完成，不跨工作截止时间补做。移动时间按律所内部每条边30秒预留，粗计划仍保持 working。

律所空间使用 firm_catalog，按角色清单配置九个区域（新增翟星办公室），办公室与茶水间包含清单设备，其余区域只记录用途。通过已有地点配置安装流程持久化，无需修改旧状态锚点。旧工作材料及历史结果保留，但当前本地工作调度不再生成模拟核对材料或进入旧文书执行链路。

法院、检察院只有到达、实际出发离开事件；客户地点为委托人沟通，警局为外勤事务。在家保留独立工作。当前版本不自动生成面向用户的工作感想或发布动态。
