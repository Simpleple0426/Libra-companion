# 移除 D2A 十维状态

生活运行系统不再保存、更新或向模型索取 D2A 十维分数。认知系统启用标志改为 `cognition_enabled`；观察处理只提交事件摘要、重要性、关键词和证据。候选预测只比较安排与实际状态，不预测分数。

粗计划、Skill、阅读/观影进度、洗衣后续、用户约定继续使用原有事实与时间。睡眠保留开始、累计秒数、自然醒和消息唤醒，不再计算困倦恢复。旧实验时间账本及其运行调用已删除；正式数据迁移停用旧计分时钟。

`scripts.retire_life_needs --apply` 必须在后端停止后运行，先获取 worker 文件锁和 SQLite 备份，再迁移当前状态、认知/睡眠配置及未完成的认知调度任务。进度、实际活动、约定和历史事件保持不变。历史回执和旧模型调用作为审计记录保留，进入新模型调用的结构化历史数据会过滤退役字段。迁移可重复执行。

生活状态 API、聊天生活上下文、主动联系的生活快照不再提供十维字段。聊天系统另有独立 `domains.affect` 情绪与关系需求模型，不属于 D2A 十维，保持原有行为。
