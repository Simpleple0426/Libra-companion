# 独立工具

[watch_together](watch_together/README.md) 是用于另一台 Windows 电脑的轻量观影采集页面，评论回到现有左然聊天通道。

[vtuber_bridge](vtuber_bridge/README.md) 将 Open-LLM-VTuber 的电脑端文字和图片输入接到现有左然 Agent，目前为接入实验版。

[keyboard_status](keyboard_status/README.md) 是供键盘换图电脑使用的状态读取工具，可独立复制使用，不依赖后端 Python 包。

后端维护命令统一放在 [`backend/scripts/`](../backend/scripts/README.md)；新建独立客户端工具放在本目录。
