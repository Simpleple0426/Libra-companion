# 在另一台 Windows 电脑上和左然看电影

## 第一次使用

1. VPS 后端与 Caddy 保持运行，无需开启 Tailscale。本地测试也支持直接使用本地后端地址。
2. 将整个陪看文件夹复制到观影电脑并解压。需要安装 Python 3.10 或更新版本（安装时选择 Add Python to PATH），无需安装其他 Python 包。
3. 双击 `start.cmd`，用 Edge 或 Chrome 打开自动出现的本机页面。
4. 展开“连接左然”，后端地址填写 VPS 的 `C:\Caddy\libra-app-address.txt` 中的完整内容（包括 `/connect/` 后面的随机密钥）；陪看连接码填写 VPS `C:\Libra\config\secrets\watch_together.token` 文件中的内容。两个字段都是私人信息，不要截图或分享。私有配对包可能已包含这些配置，通用包不包含任何凭据。
5. 点击“选择电影窗口，开始陪看”，选择播放器窗口或浏览器标签页。建议打开影片字幕。
6. 评论会出现在这个页面，以及手机 App 的电影室里；普通聊天页不显示观影消息。

## 观影方式

### 直接读画面里的字幕

无需上传字幕：打开播放器的字幕，并确保字幕出现在共享画面中。左然分析截图时会尝试阅读清晰可辨的字幕，结合画面和此前的简短剧情摘要理解当前情节。保持安静时也会更新摘要。采样频率不变，漏掉的对白不会补猜；这不是连续字幕采集，也不识别音轨。截图中的对白用于理解，不直接保存为逐字名句。

网页版的「截图里读到的字幕」会显示最近一次分析的播放时间和识别文字。空结果显示「未读到清晰字幕」，没有返回该字段则显示「本轮未返回识别结果」。没有发表评论也能显示字幕；这不是实时连续识别，文字可能有误，需要你对照画面核对。

### 可选字幕文件和播放进度

支持导入 SRT / VTT 字幕（UTF-8，也尝试兼容 GB18030，文件不超过500KB）。完整文件只在观影电脑解析，不上传给左然后端。“核对已播放的字幕”可用于检查字幕版本和时间是否匹配。

先在播放器暂停到要开始的位置，在页面填写相同的“播放器当前时间”，例如 `00:12:30`，选择实际播放倍速，然后开始陪看并同步播放影片。选择窗口和连接会有耗时，开始后可再次填写播放器当前时间并点击“校准播放时间”。

这不是自动读取外部播放器进度：暂停影片时也点“暂停陪看”，恢复时同时继续；快进或回退后重新校准。校准会清空临时剧情摘要、拦截旧进度的迟到评论，但不能删除原 Codex 主线程已经接触过的情节，提示词也明确禁止引用当前进度之后的内容。

每次分析提供上次成功分析以来已播放完的字幕，最多回看10分钟、500条、18000字；首次开始或校准只取最近2分钟，避免把快进跳过的整段内容补给他。超过上限时优先保留较近字幕。无字幕也可使用画面模式。

页面“最近分析”显示已分析进度和字幕条数。当前不采集声音，也不会自动从视频网站提取字幕。

这是抽样画面陪看，不传完整影片、不采集音轨。页面每15秒尝试发送最新画面；后端按所选频率最多每1、2或5分钟调用一次现有左然 Agent，且允许保持安静。模型生成较慢时不会排队堆积新观察。

暂停电影、快进或切换影片时，请先暂停/结束陪看。客户端不能自动知道外部播放器的播放进度。切换影片应结束后重新开始，以清空临时剧情摘要。

点“暂停陪看”即停止发送新画面；点“结束”同时停止屏幕采集。关闭页面后会尝试结束会话，连接异常时后端会话90秒后失效；暂停或失效期间不发送迟到评论。

画面仅临时用于推理，不写入聊天相册，临时文件在模型调用结束后删除。模型服务/CLI 自身可能保留会话输入；现有 Agent 的主会话会接触这些影片内容。后台保存调用追踪，评论标记为 movie_watch，不作为用户发言写入个人记忆。

不要最小化被共享的播放器窗口；部分播放器最小化后可能停止提供画面。受保护视频可能黑屏。发生黑屏或看不到字幕时先结束共享，换可正常捕获的播放来源。

## 手机电影室

进入电影室即可和左然聊天，顶部显示正在观看的电影；日历按钮可按天查询观影聊天。电影清单分为左然自己的片单、我们一起看。共同观影记录保留观看日期和最近同步的进度。影片详情可以查看实际字幕中摘录的名句，确认「我们已经看完了」后请左然根据实际观影内容写影评。结束共享只代表暂时停止，不自动标记看完。

观影评论和电影室对话仍保存在 messages 表，来源分别为 movie_watch 和 movie_chat；普通聊天的历史、增量、按日查询、搜索和收藏均排除这些来源。旧观影评论会出现在电影室，但没有关联的新电影记录不会倒推生成。

## 后端与维护

端点位于 `/watch-together`，需要专用 Bearer 连接码，保存在后端 `config/secrets/watch_together.token`。显式开启陪看独立于日常主动消息总开关，但仍尊重睡眠状态和已有对话边界。用户新发消息时，过时的观影评论会被原有投递流程拦截。

`connection.json` 包含私密连接码，不要公开分享。此方案沿用左然已有模型，不需要 Open-LLM-VTuber 环境；此前 VTuber 适配器保留为后续形象/语音入口。
